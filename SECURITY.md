# Security

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report them privately instead, for example:

- Use **GitHub Security Advisories** for this repository (**Security** tab → **Report a vulnerability**), if that feature is enabled, or
- Contact the repository maintainers through a private channel.

Include enough detail to reproduce or understand the issue. We will work with you on a fix and disclosure timeline.
